# Minesweeper

[English](README.md) · [Русский](README.ru.md)

Цветная консольная реализация классического «Сапёра» на C++.

## Возможности

- Поле 9×9 с 10 скрытыми минами
- Цветной вывод: голубой — закрытая клетка, красный — мина, жёлтый — числа, белый — пустая клетка

## Начало работы

Нужен компилятор C++ (например, `g++`).

```bash
g++ Minesweeper.cpp -o Minesweeper
./Minesweeper
```

## Использование

Вводите координаты в формате `строка столбец` и старайтесь не попасть на мину.
